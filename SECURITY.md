# Security Policy

## Supported versions

| Version   | Supported          |
| --------- | ------------------ |
| v0.1-beta | Best-effort        |

## Reporting a vulnerability

Please **do not** open public GitHub issues for security vulnerabilities.

Report privately by opening a [GitHub Security Advisory](https://github.com/William2333ZZ/OpenAgentOS/security/advisories/new)
or contacting the repository maintainer.

Include:

- Affected component (kernel, console, remote, OTA, etc.)
- Steps to reproduce
- Impact assessment

We aim to acknowledge reports within 7 days.

## Scope notes

OpenAgentOS v0.1-beta is a research / field-pilot sub-OS running in QEMU.
Remote Console and OTA features are stubs and must not be exposed to untrusted
networks without additional hardening.
