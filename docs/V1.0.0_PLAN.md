状态：**QEMU GA 已交付（2026-06）**；真板 LTS 仍为规划

前序：[V0.9.0_PLAN.md](./V0.9.0_PLAN.md)  
索引：[RELEASE_ITERATIONS.md](./RELEASE_ITERATIONS.md) · [V7_IMPLEMENTATION.md](./V7_IMPLEMENTATION.md) §6.2

---

## 1. 主题

**AgentOS 1.0 GA**：可对外承诺 LTS 的 Agent 原生操作系统——**ABI 冻结**、**双平台产品内核**、**≥1 真板 smoke**、**集成商 runbook**。

一句话：**从「可演示子 OS」到「可签 POC 合同的最小生产基线」。**

---

## 2. GA 退出标准（汇总）

摘自 [V7_IMPLEMENTATION.md](./V7_IMPLEMENTATION.md) §6.2，与产品 semver 对齐：

| # | 维度 | 1.0.0 要求 | 验收 |
|---|------|------------|------|
| 1 | **硬件** | ≥1 RISC-V SBC + ≥1 x86 工控/无头 PC smoke | `check-board-smoke` |
| 2 | **安全** | OTA Ed25519 强制、audit 路径、CVE 清零 | `check-0.9.0` + 审计清单 |
| 3 | **运维** | Fleet + Remote + 告警阈值文档 | `docs/PRODUCTION.md` |
| 4 | **发布** | stable/beta 双 channel；LTS ≥12 月安全补丁 | Release 流程 |
| 5 | **测试** | CI fast/standard/nightly 全绿 | GitHub Actions |
| 6 | **ABI** | syscall + Tool 表冻结声明 | `docs/ABI_STABILITY.md` |

## 3. 交付物

| 子项 | 交付 | 说明 |
|------|------|------|
| 产品版本 | `OPENAGENTOS_VERSION="1.0.0"` | `include/version.h` |
| 内核 | `kernel-console-v100.elf` + `kernel-x86-1.0.0.elf` | 继承 0.8.0 全栈 + 0.9.0 安全 |
| 真板 BSP | ≥1 DTB/平台表（如 VisionFive2 或 QEMU 外推 SBC） | smoke 非 full 驱动 |
| 文档包 | `PRODUCTION.md`、`ABI_STABILITY.md`、`INTEGRATOR.md` | 集成商 onboarding |
| LTS 政策 | `SUPPORT.md`：12 月 patch、24 月 security | GitHub Wiki 或 docs |
| GA check | `make check-ga-1.0` | 聚合 0.6.0 + 0.6.4 + 0.7.0 + 1.0.0 banner ✅ |

**非目标（1.0.0）**：

- 全功能 Desktop/GPU 产品化  
- 多厂商 Mesh 互联生产网  
- 商业 SLA 法律文本（POC 合同另议）

## 7. CI 与 Release 流程

```bash
# PR → fast
make check-0.1.0 check-0.3.0 check-console-x86-all

# main merge → standard
make check-0.4.0 check-x86-0.4.0

# nightly
make check-0.5.0 check-0.8.0 check-0.9.0

# release tag v1.0.0
make check-ga-1.0
```

Release 工件：内核 ELF、OTA 包、SBOM（[THIRD_PARTY.md](./THIRD_PARTY.md)）、签名 pubkey。
