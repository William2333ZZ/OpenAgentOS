## 主题

**Security minor**：OTA 包 **format-2**，manifest 含 **HMAC-SHA256**（开发密钥 `openagentos-ota-dev-key-v1`）；与 legacy CRC format-1 并存。

---

## 快速开始

```bash
make check-0.7.0       # ota-sign 自测 + kernel-ota.elf + check-ota
python3 tools/ota-sign.py --elf worker-ota-v1.agent --out /tmp/signed.agentpkg \
  --name worker --version 0.7.0 --install /agent/1/w.agent
```

---

## 实现要点

| 组件 | 说明 |
|------|------|
| `kernel/ota.c` | 校验时 manifest 的 hmac 字段置零后 SHA256(key‖body) |
| `tools/ota-sign.py` | 生成 format-2 包 |
| `kernel-ota.elf` | 含 `kernel/ota.o` + mbedTLS SHA256 |
| `worker-ota-v*.agent` | 链接 @ `0x80500000`（与静态用户段分离） |
