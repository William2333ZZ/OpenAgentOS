日期：2026-06-08

## 定位

**v0.2-rc** 在 v0.1-beta 基础上补齐：

1. **RISC-V v7 全栈**（不再使用 fleet/policy stub）
2. **Policy 文件加载**（种子 `/sys/policy/active` + `/policy load`）
3. **分项验收**（Fleet x86 子集、Console v7 RISC-V）

---

## 快速开始

```bash
make kernel-x86-v02-rc.elf
make run-x86-v02-rc
make check-v0.2-rc          # x86 产品候选 (~4s)
make check-console-v7       # RISC-V v7 (~5s)
make check-fleet-x86        # x86 Fleet 子集 (~4s)
```

Banner：`OpenAgentOS v0.2-rc — dual-platform v7 + policy load`

---

## Console 演示

```
/policy load               # 从 /sys/policy/active 加载 deny 10
/policy probe 10           # 期望 deny
/policy allow 10
/policy probe 10           # 期望 allow
/fleet push
/quit rc
```
