## 定位

**0.4.0** 将 Fleet ingest 与 Remote Console 从 **HTTP_FAUX / ping 桩** 升级为 **Guest 内真 TCP/HTTP**（RISC-V VirtIO-net + QEMU slirp）。产品验收以 **RISC-V** 为准；x86 PCI VirtIO-net 为实验分支（见 [V0.6.0_PLAN.md](./V0.6.0_PLAN.md)）。

| 能力 | 0.3.0 | 0.4.0 |
|------|-------|-------|
| Fleet ingest | HTTP_FAUX POST | `net_http_post` 经 VirtIO-net |
| Remote | `/remote ping`（faux） | `/remote connect` TCP + `LINK`/`PONG` |
| 网络栈 | 无 | MMIO `virtio-net-device` + slirp DHCP |
| 验收平台 | x86 | **RISC-V `virt`** |

---

## 快速开始

```bash
# 终端 1：宿主机服务（check 脚本会自动拉起）
python3 tools/fleet-collector.py --host 0.0.0.0 --port 8765
python3 tools/remote-gateway.py --port 5557

# 终端 2
make run-riscv-0.4.0
make check-0.4.0          # 别名 check-remote-console (~13s)
```

---

## Console 演示序列

```
/remote enable
/remote connect              # TCP → 10.0.2.2:5557，期望 PONG
/fleet push                  # 写入 /agent/0/fleet.json
/fleet ingest http://10.0.2.2:8765/ingest
/quit 0.4.0
```

验收 log 关键字：`[virtio-net] driver ready`、`[remote] tcp ok`、`[fleet] ingest net ok`、`0.4.0 demo complete`。

## 内核与模块

| 组件 | 路径 | 说明 |
|------|------|------|
| 产品内核 | `kernel-console-v040.elf` | RISC-V Console + v7 栈 + netstack |
| 网络 | `kernel/netstack.c` · `kernel/virtio_net.c` | ARP/DHCP/TCP/HTTP |
| Fleet | `kernel/fleet.c` | `FLEET_CMD_INGEST` 走 `net_http_post` |
| Remote | `kernel/remote.c` | `REMOTE_CMD_CONNECT` TCP 客户端 |
| Demo | `user/demo_v040.c` | 自动编排上述命令 |
