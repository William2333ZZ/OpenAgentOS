## 交付

|----|------|
| Policy net 规则 | ramfs `/sys/policy/active` 增加 `net_allow host:port` |

## check 场景

1. 默认 deny 非白名单 host → ingest 失败 `EPERM`  
2. allow collector → ingest 成功  
3. `/llm` deepseek 需 allow `api.deepseek.com:443`（或 blanket `*:443` 规则，文档化）
