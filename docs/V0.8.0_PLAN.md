# OpenAgentOS 0.8.0 — 设计草案

状态：**规划中**（未交付）  
基线：**0.7.0**（HTTPS fleet + router）  
目标窗口：2027 Q1–Q2  
前序：[V0.7.0_PLAN.md](./V0.7.0_PLAN.md) · 后续：[V0.9.0_PLAN.md](./V0.9.0_PLAN.md)  
索引：[RELEASE_ITERATIONS.md](./RELEASE_ITERATIONS.md)

---

## 1. 主题

**双平台产品内核收敛**：同一 semver **0.8.0** 下，RISC-V 与 x86 均提供 **net + fleet + remote + /llm** 完整 Console 栈，验收对称。

一句话：**不再「RISC-V 产品 / x86 实验」双轨，而是双平台同等 Release gate。**

---

## 2. 动机

| 现状 | 问题 |
|------|------|
| RISC-V：`kernel-console-v050.elf` 全功能 | x86 仅有 `kernel-x86-0.4.0`（net，无 llm） |
| Makefile 双轨：`CONSOLE_V050_RV_OBJS` vs `X86_V040_OBJS` | 功能漂移、回归遗漏 |
| 0.6.0 只验收 x86 0.4 能力 | 用户需在两个版本号间切换认知 |
| 集成商 POC | 需要「选 x86 或 RISC-V 同一套命令」 |

---

## 3. 交付物

| 子项 | 交付 | 验收 |
|------|------|------|
| RISC-V 产品内核 | `kernel-console-v080.elf` | `check-0.8.0-riscv` |
| x86 产品内核 | `kernel-x86-0.8.0.elf` | `check-0.8.0-x86` |
| 统一 demo | `demo_v080`（RV + x86 各一份或共享逻辑） | 相同 Console 序列 |
| x86 /llm | `llm_deepseek` + PCI net + mbedTLS x86 移植 | `check-0.8.0-x86` 含 HTTPS |
| 聚合 gate | `make check-0.8.0` → 跑双平台 | CI release 层 |
| 文档 | [VERSIONING.md](./VERSIONING.md) 双行合并为「0.8.0 双平台」 | — |

**非目标（0.8.0）**：

- 合并为**单一 ELF**（仍双产物，同 semver）
- Desktop/GPU Console（工程 v5.4 已存在，非产品 gate）
- OTA 签名强制（0.9.0）

---

## 4. 退出标准

```bash
make check-0.8.0              # 聚合
make check-0.8.0-riscv        # ~90s，等同加强版 0.7.0/0.5.0
make check-0.8.0-x86          # ~90s，x86 PCI net + /llm + fleet TLS
```

两平台 **同一命令序列**：

```
/remote enable → connect → fleet push → fleet ingest https://...
/llm --backend faux ...
/llm What is 17+25? ...
/quit 0.8.0
```

## 5. 架构（内核收敛策略）

```
                    ┌─────────────────────────────────┐
                    │  ARCH 无关（共享 .o）            │
                    │  netstack fleet remote llm_*    │
                    │  tls_client router console_svc  │
                    └───────────────┬─────────────────┘
                                    │
              ┌─────────────────────┴─────────────────────┐
              ▼                                           ▼
    kernel-console-v080.elf                    kernel-x86-0.8.0.elf
    platform_riscv_virt                        platform_x86_v08
    virtio_net (MMIO)                          virtio_pci_net
    kernel_v080_riscv.c                        kernel_v080_x86.c
```

**Makefile 目标**：抽取 `CONSOLE_V080_COMMON_OBJS`，平台仅追加 HAL + demo + platform 对象。

---

## 6. 实现要点

| 任务 | 说明 |
|------|------|
| `X86_V080_OBJS` | 在 `X86_V040` 基础上 + `llm_deepseek_x86` + `tls_client` + mbedTLS + `router_svc` |
| x86 mbedTLS | 复用 `kernel/mbedtls_port.c`，确认 x86 堆栈与 entropy |
| DNS | x86 同 0.5.0：slirp DNS → DoH |
| Banner | `-DOPENAGENTOS_VERSION=\"0.8.0\"` 双平台一致 |
| 版本头 | `include/version.h` → `0.8.0` |

**可选 stretch**：RISC-V 合并 0.7.0 HTTPS fleet 若 0.7 未交付则一并并入 0.8.0。

---

## 7. 依赖

- **0.6.0** x86 PCI net RX 必须稳定  
- **0.7.0** HTTPS fleet + router（或 0.8.0 scope 含并 0.7 能力）  
- **0.5.0** RISC-V /llm 路径回归  

建议顺序：**0.6 → 0.7 → 0.8**，不跳过 0.7。

---

## 8. 风险与缓解

| 风险 | 缓解 |
|------|------|
| x86 mbedTLS 体积/链接 | 与 RV 共用 `third_party/mbedtls` 子集列表 |
| CI 双倍 QEMU 时间 | `check-0.8.0` 并行子 job |
| 双轨 Makefile 再次分叉 | 引入 `CONSOLE_V080_COMMON_OBJS` 单点维护 |
