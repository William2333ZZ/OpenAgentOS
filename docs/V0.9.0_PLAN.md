## 1. 主题

**安全硬化 RC**：OTA 包 **密码学签名强制验证**、Remote Console **速率限制与审计增强**、已知渗透测试项修复。

一句话：**0.9.0 是 1.0 GA 前的安全 Release Candidate，默认拒绝未签名 OTA。**

---

## 2. 动机

| 现状 | 问题 |
|------|------|
| `ota.c` 使用 CRC32 `sig` 字段 | 非密码学安全，可被篡改 |
| `ota_verify` 失败仍可手动绕过（stub 路径） | 字段部署风险 |
| Remote TCP token 无速率限制 |  brute-force / 扫端口 |
| audit 分区可写可轮转 | 未做完整性链 |

---

## 3. 交付物

| 子项 | 交付 | 验收 |
|------|------|------|
| OTA Ed25519 签名 | manifest 新字段 `sig_ed25519[64]` + 公钥烘焙 | `check-ota-signed` |
| 强制 verify | `ota_apply` 无有效签名 → `EPERM` | check 负例 |
| 签名工具 | `tools/ota-sign.py` + `mk-ota-pubkey.sh` | 文档 |
| Remote 硬化 | 连接失败退避、单会话、audit 记录 | `check-0.9.0` log |
| Fleet mTLS（可选） | client cert 或 pinned CA | stretch，不阻塞 gate |
| 产品版本 | `0.9.0` Banner，继承 0.8.0 全栈 | `make check-0.9.0` |

**非目标（0.9.0）**：

- FIPS 合规  
- 完整 TPM 集成（1.0+ BSP）  
- Mesh 生产加密（optional 继续 host relay）

---

## 4. 退出标准

```bash
make check-0.8.0           # 回归
make check-ota-signed      # 新建：有效包 apply OK，篡改包 reject
make check-0.9.0           # 新建：0.8 栈 + OTA 负/正例 + remote audit log
```

**check-0.9.0 附加断言**：

- `[ota] verify fail: bad signature` 对篡改包  
- `[ota] applied` 仅对 `ota-sign.py` 签名包  
- `[remote] rate limit` 或连接拒绝 log（快速重试场景）  
- `[audit] remote connect` 条目存在

## 5. 架构

```
OTA 包布局（扩展）
┌──────────────────┐
│ ota_manifest     │  magic, version, channel, elf_offset
│                  │  sig_crc32 (legacy, 可选保留)
│                  │  sig_ed25519[64]   ← 新增
│                  │  pubkey_id
├──────────────────┤
│ ELF payload      │
└──────────────────┘

verify 流程:
  ota_parse → ed25519_verify(manifest_hash, sig, baked_pubkey)
           → fail → EPERM，不 apply
           → pass → 继续 channel + CRC 校验
```

**密钥管理**：

- 开发：`generated/ota_pubkey.h`（与 deepseek_key 类似，不入 git 私钥）  
- 生产：集成商替换 pubkey，私钥 offline 签名

## 6. 实现要点

| 模块 | 文件 | 改动 |
|------|------|------|
| 签名验证 | `kernel/ota.c` | 引入 minimal ed25519 或 mbedTLS PK verify |
| Manifest | `include/ota.h` | 扩展 struct，bump pkg version |
| 打包 | `tools/ota-pack.py`（新建或扩展） | 生成签名包 |
| Remote | `kernel/remote.c` | 失败计数、audit 钩子 |
| Audit | `kernel/audit.c` | remote/ota 事件类型 |
| Console | `/ota verify` `/ota apply` | 已有则增强错误信息 |

**ABI**：Tool OTA 语义不变；manifest 格式 version 字段递增，旧包需重签。

## 9. 风险与缓解

| 风险 | 缓解 |
|------|------|
| ed25519 代码体积 | 使用 mbedTLS 已有曲线或 tiny 实现 |
| 旧 OTA 包不兼容 | channel=`legacy` 允许 CRC-only（0.9 过渡一版后移除） |
| 真板 pubkey 轮换 | manifest `pubkey_id` 支持多 key |
