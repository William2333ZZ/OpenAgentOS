## 定位

**0.6.x 产品线首个 patch**：在 **Agent Sandbox** 模型下，让 x86 VirtIO-net PCI 与 RISC-V 0.4.0 网络能力对齐，形成可 CI 验收的 **sandbox-net** 基线。

| 能力 | 0.5.0 | 0.6.0 |
|------|-------|-------|
| 平台 | RISC-V `/llm` | **x86** fleet + remote |
| 隔离 | cap/ns/quota（v6） | 同左 + QEMU microVM 部署层 |
| 验收 | `check-0.5.0` | **`check-0.6.0`** |

---

## 快速开始

```bash
python3 tools/fleet-collector.py --host 0.0.0.0 --port 8765
python3 tools/remote-gateway.py --port 5557

make run-x86-0.6.0
make check-0.6.0          # ~20s
```

---

## 关键修复

- `virtio_pci_net.c`：移除非法 `queue_enable=0`，恢复 PCI RX（DHCP/TCP/HTTP）

---

## Console 序列

```
/remote enable → /remote connect → /fleet push →
/fleet ingest http://10.0.2.2:8765/ingest → /quit 0.6.0
```
