# OpenAgentOS v0.1-beta — GA 子操作系统（x86 PC）

日期：2026-06-04  
基线：v6.5 + v7.0–v7.3 能力合并  
产物：`kernel-x86-v01-beta.elf`

---

## 1. 定位

**v0.1-beta** 是在当前 PC（QEMU `x86_64-pc`）上可完整运行的 **OpenAgentOS 子操作系统 GA 候选**，整合：

| 能力 | 模块 | Console |
|------|------|---------|
| v6 多租户 / 审计 / 命名空间 / 配额 | tenant, audit, namespace, quota | `/tenant` `/audit` `/namespace` `/quota` |
| v7.0 Fleet 遥测 | `kernel/fleet.c` · `TOOL_FLEET` (22) | `/fleet status|push|probe` |
| v7.1 Remote Console | `kernel/remote.c` · `TOOL_REMOTE` (24) | `/remote status|enable|disable` |
| v7.2 Policy-as-Code | `kernel/policy.c` · `TOOL_POLICY` (23) | `/policy status|load|deny|allow|probe` |
| v7.3 Agent Mesh MVP | `kernel/mesh.c` · `TOOL_MESH` (25) | `/mesh status|beacon|probe` |

RISC-V 内核仍链接 v7 **stub**（保持 `check-console-*` 回归）；完整 v7 栈仅在 x86 v0.1-beta 内核启用。

---

## 2. 快速开始

```bash
# 构建
make kernel-x86-v01-beta.elf

# 交互运行（UART Console）
make run-x86-v01-beta

# 全链路验收（~4s）
make check-v0.1-beta
```

启动 Banner 示例：

```
========================================
  OpenAgentOS v0.1-beta — v0.1-beta GA — Field Pilot sub-OS
  platform: x86_64-pc (x86_64)
========================================
```

---

## 3. Console 演示脚本

在 `agentos>` 提示符下：

```
/fleet status
/fleet push
/policy deny 10          # 拒绝 TOOL_GPIO
/policy probe 10
/remote enable
/mesh beacon
/tenant status
/quota status
/quit beta
```

`/quit beta` 结束 demo 并输出 `v0.1-beta demo complete`。

## 4. 运维侧（Host）

| 组件 | 路径 | 说明 |
|------|------|------|
| Fleet 缓存 | `/agent/0/fleet.json` | `push` 写入 JSON 快照 |

| Remote token | `/sys/console/token` | 默认 `agentos-beta` |
| Host 代理 | `tools/remote-console.py` | TCP :5557 stub（开发用） |

## 6. 与 v7 规划 / GA 1.0 关系

- **v0.1-beta**：QEMU x86 可重复验收的 **字段试点 GA**（本仓库当前交付）
- **v7.x 分项 check**：可逐步从 `check-v0.1-beta` 拆出独立 `check-console-fleet` 等
- **GA 1.0（2027 Q3）**：真板 BSP、签名链、LTS 渠道 — 见 [V7_IMPLEMENTATION.md](./V7_IMPLEMENTATION.md) §6

---

## 7. 已知限制

- x86 无 VirtIO-net：Fleet `probe` / Remote 为 host stub，非真实 HTTP/TCP 栈
- Mesh 为单设备 beacon，无跨 QEMU 实例桥接
- Policy 仅支持 tool deny 列表，无 path prefix 规则（v7.2 完整 DSL 后续迭代）
