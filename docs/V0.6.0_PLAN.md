## 1. 主题

**双平台网络 parity**：让 **x86 VirtIO-net PCI** 达到与 RISC-V MMIO net 相同的 Fleet ingest + Remote TCP 验收标准，并为后续 x86 上跑 `/llm` 铺路。

一句话：**RISC-V 已证明的网络 Console 栈，在 x86 PC 上可自动化验收。**

---

## 2. 动机

| 现状 | 问题 |
|------|------|
| 0.4.0 / 0.5.0 产品 gate 仅 RISC-V | x86 开发者无法在同一 semver 下验收 net/llm |
| `kernel-x86-0.4.0.elf` + `virtio_pci_net.c` | RX 路径不完整，无 `check-x86-*` |
| slirp 在 x86 `-netdev user` 已可用 | 缺驱动稳定性与 CI 脚本 |
| Makefile `X86_V040_OBJS` 已链 netstack | 距 check 绿仅差 RX + 脚本 |

## 4. 退出标准

```bash
make check-0.5.0          # RISC-V 回归仍绿
make check-x86-0.4.0      # 新增：x86 virtio-net PCI + fleet ingest + remote TCP
```

`check-x86-0.4.0.sh` 应对标 `check-0.4.0.sh`：

```bash
qemu-system-x86_64 -machine pc -nographic -kernel kernel-x86-0.4.0.elf \
  -netdev user,id=net0 -device virtio-net-pci,netdev=net0 ...
```

**log 关键字**（与 0.4.0 RISC-V 一致）：

- `OpenAgentOS 0.4.0` 或 `0.6.0`（见 §8）
- `[virtio-net] driver ready` 或 `[virtio-pci-net] ready`
- `[remote] tcp ok`
- `[fleet] ingest net ok`
- `0.4.0 demo complete` 或 `0.6.0 demo complete`

**典型耗时**：~15–30s（standard CI 层）。

## 5. 架构

```
Console /fleet ingest /remote connect
    → fleet.c / remote.c（ARCH 无关）
    → netstack.c TCP/HTTP
    → virtio_pci_net.c（x86）  ← 0.6.0 修复重点
    → QEMU slirp 10.0.2.2
```

对照参考：`kernel/virtio_net.c`（RISC-V MMIO 已实现路径）。

---

## 6. 实现要点

| 步骤 | 文件 | 说明 |
|------|------|------|
| 1 | `kernel/arch/x86/virtio_pci_net.c` | RX descriptor 环、used ring 更新、中断/轮询 |
| 2 | `kernel/netstack_x86.c` | 确认 `netstack_ready()` 在 DHCP 后 true |
| 3 | `user/demo_v040.c` 或 `demo_v060_x86.c` | x86 自动编排命令（可复用 v040 逻辑） |
| 4 | `scripts/check-x86-0.4.0.sh` | FIFO 喂命令 + log grep |
| 5 | `Makefile` | `check-x86-0.4.0`、`.PHONY` 注册 |

**ABI**：不新增 Tool ID；复用 0.4.0 Console 命令。

## 8. 版本策略（0.6.0 特有）

两种可选方案（实现前择一）：

| 方案 | 说明 | 优点 |
|------|------|------|
| **A：semver 0.6.0** | x86 check 绿即 bump `version.h` → 0.6.0 | 用户可见「x86 net 里程碑」 |
| **B：产物 semver 0.4.0** | 内核仍标 0.4.0，产品文档称 0.6.0 = x86 gate | 与 RV 0.4 能力对齐，少混淆 |

**推荐方案 A**：0.6.0 作为独立 minor，RV 仅回归、不 bump 产物亦可；或 RV 同步 bump 到 0.6.0（无新 feature，patch 级文档说明）。

---

## 9. 风险与缓解

| 风险 | 缓解 |
|------|------|
| x86 PCI net 调试周期长 | 先 RV log 对照单测 ARP/DHCP，再 HTTP |
| CI 时间膨胀 | x86 check 独立 target，不进 fast 层 |
| slirp DNS 差异 | 与 0.5.0 相同策略（本版不涉及 HTTPS） |
| QEMU pc 无 net 设备 | `run-x86-0.4.0` 已带 `-device virtio-net-pci` |
