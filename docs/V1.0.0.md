日期：2026-06

## 定位

**1.0.0** 为 **QEMU 可验收的产品 GA**：在 0.6.x Agent Sandbox Runtime 与 0.7.0 OTA 签名之上，提供单一聚合 gate，作为对外 semver **MAJOR=1** 基线。

| 维度 | 1.0.0 QEMU GA | 完整 LTS（规划） |
|------|---------------|------------------|
| 验收 | `make check-ga-1.0` | 真板 smoke + 集成商 runbook |
| 平台 | RISC-V virt + x86 pc（QEMU） | ≥1 SBC + 工控 PC |
| OTA | format-2 HMAC-SHA256 | Ed25519 强制（后续 minor） |

---

## 快速开始

```bash
make check-ga-1.0      # ~60s：0.6.0 + 0.6.4 + 0.7.0 + 1.0.0 banner smoke
```

单 patch 回归：

```bash
make check-0.6.0 check-0.6.4 check-0.7.0
make kernel-console-v100.elf   # OpenAgentOS 1.0.0 banner
```

## GA gate 组成

| 步骤 | check | 说明 |

| OTA 安全 | `check-0.7.0` | format-2 签名 +  legacy `check-ota` |
| 产品 banner | `kernel-console-v100.elf` | `OpenAgentOS 1.0.0` smoke |

## 源码版本

- `include/version.h` → `OPENAGENTOS_VERSION "1.0.0"`
- 静态用户 Agent：`linker.ld` @ **0x80400000**
- 动态 OTA/ELF Agent：`linker-agent.ld` @ **0x80500000**

---

## 已知限制

- **`check-0.6.1`**：`/fleet ingest https://…:8443` 在 TLS 长 syscall 路径上仍有 console page fault，未纳入 GA gate。
- **DeepSeek `/llm`**：经 router syscall 的 deepseek 路径在部分内核上有用户态边界问题；回归仍用 `check-0.5.0` 与 `check-0.6.2`（faux backend）。
- **真板 / LTS SLA**：见 [V1.0.0_PLAN.md](./V1.0.0_PLAN.md)（目标 2027 Q3）。
